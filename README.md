# Курсовая работа: расстояние Левенштейна

Тема: «Реализация алгоритма вычисления расстояния редактирования (Левенштейна)
с оптимизацией памяти и параллельным вычислением».

## Что где лежит

```
Курсовая_Левенштейн/
├── Документ/
│   ├── Курсовая_Левенштейн.docx   — пояснительная записка (готовый документ)
│   ├── Курсовая_Левенштейн.pdf    — та же записка в PDF (для просмотра)
│   ├── images/                    — рисунки для записки
│   └── _build/                    — скрипты сборки документа (служебные)
│       ├── make_figures.py        — построение рисунков
│       ├── make_docx.py           — сборка .docx
│       └── finalize.ps1           — обновление оглавления в Word
└── Программа/                     — исходный код (отдельная папка)
    ├── src/levenshtein/           — 8 классов Java
    ├── build.bat                  — компиляция
    ├── run.bat                    — демонстрационный запуск
    ├── test.bat                   — тесты
    ├── bench.bat                  — замеры времени
    ├── results.md / results.csv   — результаты замеров
    ├── test-results.txt           — протокол тестирования
    └── README.md                  — описание программы
```

## Документ

Пояснительная записка собрана по шаблону МИРЭА: титульный лист, содержание,
введение, два раздела, заключение, список из 17 источников и три приложения
(код программы, инструкция пользователя, примеры входных и выходных данных).
Объём — 46 страниц.

Перед сдачей нужно заполнить на титульном листе: кафедру, дисциплину, группу,
ФИО студента и руководителя (оставлены прочерки).

Оглавление в документе уже сформировано. Если оно сбилось, откройте документ
в Word и нажмите Ctrl+A, затем F9 (или ПКМ по оглавлению → «Обновить поле»).

## Программа

Требуется JDK 17+ (проверено на JDK 21). Сборка и запуск:

```
cd Программа
build.bat
test.bat
bench.bat
```

Подробности — в `Программа/README.md`.
